# Changelog

## 0.1.0 - 2026-06-01

- Added a Grafana app plugin with a nested device-action panel.
- Added server-side REST action execution, validation, cooldowns, role policies, and audit logs.
- Added visual action and connector editors, encrypted bearer-token storage, and a provisioned demo environment.
- Added Go tests, Playwright end-to-end tests, CI coverage, release packaging, and publishing guidance.
- Normalized public catalog IDs to `asim-deviceaction-app` and `asim-deviceaction-panel`.
